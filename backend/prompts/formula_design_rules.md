# 公式拆解规范（仅当动画涉及数学 / 物理公式时）

把公式当「一组角色」，而不是一张图：

- 公式拆成有序的 `latex_parts`（如 `["v","=","g","t"]`）；
- 每个可讲解的项给一句大白话（plain）与含义（means）；
- 同一类含义的符号用同一种颜色身份（如「运动量」一色、「作用力」一色、「时间」一色），整片保持一致；
- 用 `TERM_TOUR` 逐项讲解（对 `MathTex[i]` 高亮 + 旁注），不要对整块公式笼统念；
- 提前点破常见误读（如「理想自由落体与质量无关」）；
- 公式必须先有视觉铺垫，再 `REVEAL_FORMULA`，且停留 ≥ 1.2 秒。

不涉及公式的学科（历史 / 语文 / 地理等）忽略本节。
