# 教学动画设计原则（先教学，后符号）

1. **先直觉后符号**：先用图像 / 运动 / 变化建立直觉，再引入符号、公式、定义。公式不要一开场就出现。
2. **每段教一件事**：每个 shot 必须能用一句话说清「这段教什么」（teaches）。
3. **有头有尾**：整片开头要有一个 HEADLINE（大标题点题），结尾要有一个 TAKEAWAY（把核心结论留给学生）。
4. **看得到变化**：让学生看到核心变量「怎么变」（位置 / 数值 / 形状随时间动），而不是把静态文字写出来就完事。
5. **视觉与符号挂钩**：画面对象与数学符号要建立对应（同一含义用同一颜色 / 位置呼应）。
6. **克制**：同屏文本最多 2 块；公式停留至少 1.2 秒；节奏留白（适当 wait）。
7. **别做成 PPT**：避免「每一步只是把一句话写出来」。能画图就画图、能动就动。
